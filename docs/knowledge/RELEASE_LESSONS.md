# Release Lessons

1. Engineering CI success does not satisfy the scientific release gate.
2. Scientific validation must remain fail-closed while required evidence is missing, blocked, or regressed.
3. Immutable historical evidence must not be weakened to accommodate live-source drift.
4. Release decisions must carry forward the cumulative ledger and unresolved knowledge state.
5. Cumulative lifecycle enforcement is itself release-process infrastructure: CI must validate the actual workflow, cycle-record state machine, and regression protections before the process control is accepted.
