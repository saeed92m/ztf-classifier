# Performance Lessons

Performance is measured as a vector, not a single speed score.

Required dimensions where applicable:
- runtime
- throughput
- latency
- memory
- CPU/GPU utilization
- I/O
- batch efficiency
- feature-generation time
- inference time

Optimization records must compare before/after values and explain trade-offs. A speed increase that reduces scientific validity, reproducibility, or correctness is not an accepted improvement.
