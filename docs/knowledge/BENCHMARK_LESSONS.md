# Benchmark Lessons

1. Benchmark manifests are immutable versioned contracts for source, population, labels, preprocessing, split, leakage exclusions, and provenance.
2. Benchmark input hashes must be retained with reports.
3. Regression remains release-blocking until dispositioned.
4. Missing or non-executable scientific evidence is never silently treated as pass.
5. Each benchmark execution should emit scientific results and reusable lessons/failure patterns.
6. Benchmark population, source version, and retrieval date are evidence, not incidental metadata.
