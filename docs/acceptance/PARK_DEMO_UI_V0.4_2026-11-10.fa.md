## تغییرات رابط

1. بخش «وضعیت پیشرفت» از صفحه اصلی حذف شد.
2. صفحه اصلی اکنون قابلیت‌های پیاده‌سازی‌شده نسخه فعلی را از چشم‌انداز محصول نهایی جدا می‌کند.
3. در تب کاوش منحنی نوری، راهنمای توسعه علمی QC اضافه شد.
4. توضیحات کاتالوگ OID درباره معنای شناسه، metadata، محدودیت نمونه و Hash تکمیل شد.
5. زنجیره منشأ از منبع و batch درخواست تا اعتبارسنجی، حفظ داده خام، نمایش و خروجی مستند شد.
6. محدودیت‌های هویت فیزیکی OID، کنترل مستقل r و نبود فایل اصلی ۱۵۰ ردیفی حفظ و روشن‌تر شدند.

## مرز علمی

- QC افزوده‌شده فقط راهنمای طراحی است؛ سیاست تولیدی انتخاب epoch نیست.
- هیچ epoch حذف یا فیلتر نشده است.
- هیچ OID به جرم فیزیکی مستقل نسبت داده یا با OID دیگری ادغام نشده است.
- کنترل r با نمونه g تطبیق فیزیکی نشده است.
- فایل ۱۵۰ ردیفی Objects Table بازسازی یا جعل نشده است.
- هیچ ویژگی، پیش‌بینی، طبقه‌بندی، کالیبراسیون یا نتیجه علمی جدیدی تولید نشده است.
- خط مبنای علمی v0.2.0 و انتشار نرم‌افزار v1.0.1 تغییر نکرده‌اند.
